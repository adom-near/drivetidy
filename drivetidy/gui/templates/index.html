EXIF 訊號

相機資訊（拍攝時間、相機型號）跟 size + 檔名一起比對的結果。 「conflict」是要請你手動確認的 — 兩邊都有 EXIF 但對不起來， 可能是不同相機湊巧同檔名同 size，請展開「已備份檔案的目的地對應」看那幾筆。

  • 0 strong（兩邊 EXIF 對得上）
  • 0 weak（沒 EXIF 或資訊不夠）
  • 0 conflict（請手動確認）
