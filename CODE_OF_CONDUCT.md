# Code of Conduct

DriveTidy is a small open-source project. The rules are simple:

1. **Be respectful.** Disagree about code, not about people.
2. **No harassment** of any kind — racial, sexual, gender, religion, or otherwise.
3. **Assume good faith.** Most bug reports and review comments are people trying to help.
4. **Stay on topic.** Use issues for bugs and feature requests, not for general discussion.

Violations: I'll ask you once to stop. If it continues, you'll be blocked from the repo.

Report problems by opening a private issue or emailing the maintainer (see `pyproject.toml`).
